# UX Flows

## First-Time User

Onboarding explains the thesis, privacy, and permissions. The user installs a starter Shared Boundary pack or continues with manual setup, then lands on Today.

## Add Boundary

Boundaries -> app -> surface -> action -> limit / override / chosen window -> save.

## Hit High-Risk Surface

Android detects a high-risk surface, FocusGuard evaluates the boundary, shows a Moment of Choice when needed, and logs a local event for Attention Mirror.

## Reflect

Attention Mirror shows moments reclaimed, common interrupted surfaces, and optional reason patterns without streaks, points, or shame.
