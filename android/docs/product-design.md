# Product Design

FocusGuard is an attention firewall, not a generic app blocker.

The product language is intentionally humane:

- Rules are Boundaries
- Presets are Shared Boundaries
- Stats are Attention Mirror
- Block screens are Moments of Choice
- Whitelist windows are Chosen Windows

The visual direction is Bone White, Charcoal, and Deep Sage: calm, restrained, premium, and screenshot-friendly.
