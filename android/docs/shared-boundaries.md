# Shared Boundaries

Shared Boundaries are local JSON rule packs bundled with the app in v0.1.

They are similar in spirit to AdBlock lists, but for attention traps.

Bundled packs:

- Essential
- No Shorts
- Reddit Minimal
- Creator Mode
- Evening Reset

Future versions can support local file import and GitHub raw URL import. v0.1 does not silently sync rules.
